# astrbot_plugin_monitor

AstrBot 插件：系统信息查询 + ping 测试。关键词触发，**无需 `/` 前缀、无需 `@` 机器人**，
适合去掉了唤醒前缀、避免与其它机器人 `/` 指令冲突的场景。

跨平台支持 **Windows / Linux（各发行版）/ macOS**。

## 功能

### 1. 系统信息查询
- 直接发送触发词（默认 `sysinfo` 或 `系统信息`）即可查询，`@机器人 sysinfo` 也可以。
- 仅插件配置中设置的**管理员 QQ** 可查看，其他人查询返回友好提示（默认「调用系统 API 失败，请稍后再试～」），
  不暴露权限逻辑，避免让查询者尴尬。
- 返回内容（每项一行，无分隔线、无表情）：
  - 系统运行时间（已开机时长）
  - 系统版本（自动检测真实值：Linux 读 `/etc/os-release`，Windows 报 `Windows 10/11`，macOS 报 `macOS x.x`）
  - 程序运行时长（AstrBot 进程已运行时长）
  - CPU / 内存 / 磁盘占用率（只输出占用率，不输出具体大小）
  - 系统状况分析（健康 / 良好 / 注意 / 紧张）

```
系统运行时间：3天5小时12分钟
系统版本：Debian GNU/Linux 12 (bookworm)
程序运行时长：2小时15分钟
CPU占用率：12.3%
内存占用率：68.5%
磁盘占用率：75.2%
系统状况：健康
```

### 2. ping 测试
- 直接发送 `ping`，回复 `测试完成，用时xxxms`，所有人都可触发。
- 用时为机器人**内部回复延迟**（高精度单调时钟测量）。
- 说明：QQ 平台（OneBot）只提供秒级整精度的时间戳，无法干净地测量包含网络往返的 ping，
  因此这里测的是机器人收到消息后组织回复的内部耗时，通常在亚毫秒级。

## 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 下（或通过插件市场安装），重启或热重载插件。

### 安装后必做

进入 AstrBot 管理面板 → 插件 → 系统信息查询与 ping 测试 → **配置**，
设置「允许查询系统信息的管理员 QQ」为自己的 QQ，保存并重载插件。
**不设置则所有人查询系统信息都会被拒绝**（日志中会有警告）。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `owner_qq` | string | `""` | 允许查询系统信息的管理员 QQ |
| `sysinfo_triggers` | list | `["sysinfo", "系统信息"]` | 触发词（精确匹配整条消息，不区分大小写） |
| `no_permission_reply` | string | `调用系统 API 失败，请稍后再试～` | 无权限用户查询时的回复 |
| `disk_path` | string | `""` | 磁盘占用率统计路径；留空自动选择（Linux/macOS 用 `/`，Windows 用系统盘） |

## 依赖
- `psutil`：AstrBot 自带，无需额外安装。
- 平台：消息平台不限（开发验证于 aiocqhttp / napcat）。
